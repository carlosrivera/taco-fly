# Taco Fly 🪰🌮

¿Dónde comería una mosca en CDMX?

A fruit-fly-inspired chemotaxis controller navigates a simulated olfactory
landscape generated by ~600 real taquerías (OpenStreetMap) overlaid on Mexico
City. The fly receives no routes, no coordinates, and no LLM — only local smell
samples around its current position (PRD §7, §11).

**V0 status: working prototype.** See `prd.md`.

## Run it

```bash
pnpm --dir app install
pnpm --dir app dev        # → http://localhost:5173
```

## Real connectome wiring (V1.1)

```bash
# once: 3.4 GB download (anonymously accessible GCS bucket)
curl -o data/malecns_09_simple_edgelist.feather \
  "https://storage.googleapis.com/lee-lab_brain-and-nerve-cord-fly-connectome/compiled_data/malecns_09/malecns_09_simple_edgelist.feather"
python3 scripts/extract-connectome.py   # filter to olfactory pathway (~20 s)
python3 scripts/convert-connectome.py   # local indices + glomeruli + sides
python3 scripts/add-sides.py            # (optional) side annotations
```

**What's real:** PN→KC claws, KC→MBON convergence, MBON→DN and DN→MN
partnerships, ORN/PN glomerulus identities and hemispheres.
**What's scaffolded:** ORN tuning vectors, LN/DAN wiring, VNC/optic-lobe
recurrence, and all weights (the connectome gives connectivity, not
synaptic efficacies). DAN-gated KC→MBON plasticity is the biological
learning rule (appetitive conditioning, σ PAM/PPL1).

## How it works

- **Scent model** — `S(d) = I · exp(−k·d)` per taquería, anisotropic under a
  constant simulated wind (`app/src/sim.js`).
- **Sensory encoder** — the fly samples `smell_left / forward / right`,
  `total_smell`, `smell_gradient` at antenna offsets. Nothing else.
- **Controller A: Dumb Fly** — probabilistic chemotaxis: biased random walk,
  weathervaning toward the stronger antenna, run/tumble with a refractory
  period, saturation escape (fly straight when standing on the source).
- **Controller B: Neural Fly** — a 53-neuron recurrent dynamical system
  (`aᵢ(t+1) = f(Σ wⱼᵢ aⱼ(t) + Iᵢ(t) − λaᵢ(t))`) with a weak chemotaxis prior in
  its sensory→motor wiring and random recurrent "personality". Untrained.
- **Controller C: MaleCNS** — 165,114 simulated neurons sized from the REAL
  MaleCNS v0.9 annotated connectome metadata (Lee lab male brain+VNC
  connectome, CC-BY; see `data/malecns.json`), wired with REAL connectivity
  for the olfactory pathway (see below): 2,635 ORNs across two antennae →
  real glomeruli per hemisphere (from ORN/PN cell types like `ORN_DA1` /
  `DA1_lPN`), 420 LNs (gain control), 697 PNs, 4,064 Kenyon cells with real
  claws (median 6 PN inputs, from the actual edgelist), 340 dopaminergic
  neurons gating plasticity at the real KC→MBON synapses (median 577 KC
  inputs per MBON — the fly *learns* which smell patterns pay off), 1,321
  descending neurons (169 with real MBON input), 879 motor neurons (855 with
  real DN input; 23 wing-steering MNs set turn authority), 99,138 optic-lobe
  neurons providing diffuse tone. Cast-and-thrust in clean air, hover-capture
  on source.
- **Fly lineage (V1.1)** — learned KC→MBON weights persist in localStorage:
  every MaleCNS fly inherits its ancestor's learned weights and passes on its
  own. The LINEAGE badge tracks generations and inherited taco knowledge;
  FORGET LINEAGE resets the bloodline.
- **Mortality** — energy drains while flying; each discovered taquería is a
  meal. Empty tank → the fly dies (red dot, ☠ DEAD, death card). Deterministic
  seeded runs (`mulberry32`, seed 87231).
- **Map** — MapLibre GL JS, Esri World Dark Gray basemap, glowing taquería
  points, persistent trail, discovery rings, live telemetry bar.

## Controls

- **DUMB FLY / NEURAL FLY / MALECNS** — controller selection
- **COMPARE** — runs all three headless on identical spawns & seed, tables
  tacos / km / fate (PRD §16)
- **PICK DROP POINT** — click the map to choose where the fly spawns
  (otherwise it drops on a random edge of the study area)
- **RELEASE FLY 🪰** — start the simulation (camera follows; panning stops follow)
- **1× / 4× / 16× / 64×** — simulation speed
- **RESET** — new deterministic run
- **HIDE MAP** — view only the shape the fly drew (PRD §15)
- **EXPORT PNG** — shareable screenshot with stats baked in

Typical comparison (same spawns & seed, 40 sim-min): Dumb Fly 17–168 tacos,
Neural Fly 0–3, MaleCNS 2–3. An untrained anatomically-structured connectome
scaffold loses to tuned chemotaxis — exactly the honest baseline V1 should
establish before real connectome wiring (and/or pretraining) lands in V1.1.
